# Restaurant Performance Analytics

**An end-to-end data analytics project using Python, SQL, Excel and Power BI on Zomato restaurant data.**

Restaurants generate a lot of data, but the value comes from understanding what it says about customer preferences, pricing and ordering behavior. This project takes Zomato-style restaurant data from raw records to a cleaned dataset, a SQL database, summary tables and a Power BI dashboard, and turns the results into business-oriented insights.

## Project Objectives

- Clean and prepare raw restaurant data so it can be trusted for analysis.
- Explore restaurant popularity, ratings, pricing patterns and online-ordering behavior.

## About the Data

The analysis is designed around the Zomato restaurant dataset for Bengaluru. The fields are described in [`data/raw/dictionary_data.txt`](data/raw/dictionary_data.txt) and include restaurant name, online ordering and table booking availability, rating, votes, location, restaurant type, cuisines, approximate cost for two and listed type (Buffet, Cafes, Delivery, Dine-out, Pubs and bars).

**Note on the bundled data:** to keep the repository small and the pipeline runnable out of the box, the committed `zomato_cleaned.csv`, `zomato.db` and summary table are built from a 10-restaurant sample generated by `python/create_sample.py`. The full raw file (`zomato.csv`) is not committed. To reproduce the analysis at full scale, place the full dataset in the project root as `zomato.csv` and re-run the scripts.

## What Each Part Does

### Python

- **`data_cleaning.py`** removes duplicate rows, converts ratings such as `4.1/5` to numbers (treating `NEW` and `-` as missing), strips thousands separators from cost values and converts them to numeric, and standardizes the yes/no columns. The result is saved to `data/cleaned/zomato_cleaned.csv`.
- **`eda_analysis.py`** reports the distribution of restaurant types, the online-order adoption percentage, the average rating by type and a statistical summary of rating, votes and cost. It also saves a chart of restaurant counts by type to `images/charts/`.
- **`sql_analysis.py`** loads the cleaned data into a SQLite table and runs queries for the top-rated restaurants and for average cost and rating by restaurant type.
- **`excel_summary.py`** builds a pivot-style table of restaurant counts and mean ratings by location and listed type, exported to CSV for use in Excel.

### SQL

`sql/zomato_queries.sql` holds the core business queries: the highest-rated restaurants, and average rating and cost grouped by restaurant type. The same logic is executed against the SQLite database from `sql_analysis.py`.

### Power BI

`powerbi/zomato data.pbix` is a single-page dashboard built on the cleaned table. It includes a headline KPI card, a donut chart showing the online-order split, a combo chart of restaurants by listed type and a detailed restaurant table (cost, rating, votes, cuisine, location, restaurant type and ordering options).

## Key Findings

The conclusions below come from [`reports/summary_report.txt`](reports/summary_report.txt). Because the bundled data is a small sample, treat them as a demonstration of the method and validate them on the full dataset.

1. **Online delivery:** cafes lead in online-ordering adoption, while traditional fine dining and pubs lean on in-person walk-ins.
2. **Pricing:** most restaurants cluster around moderate price points for two people.
3. **Ratings:** ratings look consistent across online and offline channels, suggesting online adoption does not hurt customer satisfaction.

**Recommendations**

- **Targeted onboarding:** campaigns could encourage traditional dining categories to adopt hybrid or digital delivery.
- **Menu optimization:** restaurants could align pricing tiers with the spending levels customers favor most.

## Getting Started

### Prerequisites

- Python 3.x and pip
- Git
- Power BI Desktop, to open the `.pbix` file
- Microsoft Excel (optional), to view the summary table

### Setup

```bash
git clone https://github.com/pocharamjayanth/Restaurant-Performance-Analytics.git
cd Restaurant-Performance-Analytics

python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate

pip install -r requirements.txt
```

### Run the pipeline

Run every script from the project root, since the scripts use relative paths.

```bash
# 1. Create the sample input (skip this if you placed the full zomato.csv in the root)
python python/create_sample.py

# 2. Clean the data
python python/data_cleaning.py

# 3. Explore, query and summarize
python python/eda_analysis.py
python python/sql_analysis.py
python python/excel_summary.py
```

Then open `powerbi/zomato data.pbix` in Power BI Desktop to explore the dashboard.

## Real-World Relevance

- **Business teams** get a repeatable workflow, from raw data to dashboard, that can be applied to any marketplace with ratings, prices and orders.

## Limitations and Future Improvements

- Re-run and validate the analysis on the full Zomato dataset rather than the bundled sample.
- Add automated data-quality checks and unit tests for the cleaning functions.
- Automate the pipeline with a single entry-point script and scheduled refreshes.
- Expand the dashboard with more pages, filters and documented metrics.
- Extend the analysis with predictive modeling, for example predicting ratings or online-order adoption.
- Move to a server-based database if data volume grows.
